# Market Peek

바탕화면과 작업 표시줄에서 코인·한국·미국 주식 시세를 확인하는 Windows 앱입니다.

[프로그램 소개와 설치 안내](https://dukichoi.github.io/programs/market-peek/) · [최신 버전](https://github.com/DukiChoi/Market-Peek-releases/releases/latest) · [버전별 다운로드](https://github.com/DukiChoi/Market-Peek-releases/releases)

## 다운로드

각 버전의 릴리스 페이지 아래 **Assets**에서 파일을 내려받으세요.

- **EXE**: 한국어 설치 안내에 따라 설치합니다.
- **7z**: 압축을 모두 푼 뒤 폴더 안의 `Market Peek.exe`를 실행합니다.
- **SHA256SUMS.txt**: 배포 파일의 SHA-256 해시입니다.

Windows 64비트용이며 Python을 따로 설치할 필요가 없습니다. 현재 설치 파일에는 코드 서명이 없어 Windows에서 게시자 확인 안내가 표시될 수 있습니다.
